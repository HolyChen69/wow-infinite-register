# 选项与坐标校准参考

## 重要原则

坐标和检测阈值**强绑定**于：显示器尺寸、屏幕分辨率、客户端版本、UI 缩放、服务器界面布局。
写死坐标在不同显示器上必然错位——所以**每次运行前都由用户在当前屏幕上实际点击采集**，
`scripts/presets/*.json` 只作为字段结构样例，绝不直接拿来跑。

采集分两步（都由 `scripts/calibrate.py` 引导）：
1. `capture` — 用户按提示逐个点击界面元素，脚本记录每个坐标并生成带默认检测框的 config。
2. `boxes` — 用户在对应界面拖拽框选检测区域（金框/光晕/绿勾/红按钮），得到精确读数。
3. `probe` — 验证各检测框在当前状态的 True/False 读数，确保判据可靠。

**只有经过当前屏幕采集并 probe 通过的 config 才能进入试跑和无限注册。** 未校准就开跑会 drift 或建错号。

  换职业必须重新定位并重新测 bright 框。

## 校准新选项的标准流程

对**每一个**新选项（新种族/新职业/新规则集/新性别），按以下步骤取得 `detect` 与 `click`：

1. 手动（或用 `desktop_ctl.py click`）把界面停留在"角色创建页 / 规则集页"，且只把
   目标项设为选中状态。
2. 截图取证：
   ```bash
   python desktop_ctl.py shot cal_<item>.png
   ```
   用看图工具定位目标图标的点击中心和检测框 `[x0,y0,x1,y1]`。
3. 采样验证选中态：把候选 `detect` 块写进临时 config，运行
   ```bash
   python register.py --config tmp.json --mode probe
   ```
   读取该维度打印的 `ok` 与数值。
4. 再点一个**非目标**项，重跑 probe，确认 `ok=False`。选中 True / 未选 False 都满足才算校准成功。
5. 把校准好的 `click + detect` 写进 preset 的 `options`，切换 `value` 到新值。
6. 用 `--mode trial --rounds 10` 试跑，确认信号节奏与原组合一致，再进入无限模式。

### detect.kind 选择指南

| kind | 适用 | 需要字段 |
|---|---|---|
| `gender` | 性别男/女（左右两图标相对比较） | `left_box`,`right_box`,`value`(male/female),`min`,`ratio` |
| `gold` | 规则集卡片金色左边框 | `box`,`min` |
| `halo` | 种族头像选中光晕 | `box`,`min_bright`,`min_gold` |
| `bright` | 职业图标整体高亮 | `box`,`min` |

### 阈值调试技巧

probe 打印的是真实比值。选中态比值设为 `min` 的约 60%~70%（留噪声余量），
未选态应明显低于 `min`。例如 druid 选中 bright=0.299、未选约 0.03~0.08，取 min=0.12。
不要把 min 设得贴近选中值，否则渲染波动会导致误判 drift。

## 分辨率变化

换分辨率后全部坐标失效，必须重新校准整套 preset。屏幕尺寸可用
`python desktop_ctl.py info` 确认（VIRTUAL_SCREEN size）。
